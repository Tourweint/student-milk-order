# 文档目录

> 项目定位：**周期性业务履约的状态管理与异常恢复**（以校园乳品配送为验证场景）。
> 建议阅读顺序：先看「基线文档」中的业务过程与可靠执行模型，再看「实验」，最后看「论文」。

## 基线文档（长期维护，不带日期）

- [业务过程与可靠执行模型.md](./基线文档/业务过程与可靠执行模型.md) — **核心抽象**：问题定义、四层模型、
  过程层与可靠性层的代码落点、父子状态机与状态聚合、不变量清单
- [可靠性设计.md](./基线文档/可靠性设计.md) — 幂等 / CAS / 行锁 / 资源台账 / 对账补偿 / 定时兜底的
  机制细节、判定口径与改动检查清单
- [系统架构.md](./基线文档/系统架构.md) — 技术栈、分层与横切机制层、模块划分、部署架构、状态机与兜底任务
- [接口文档.md](./基线文档/接口文档.md) — 全部 RESTful API 清单、通用约定、错误码
- [支付链路.md](./基线文档/支付链路.md) — 微信支付模拟链路与同步模拟支付、两条链路共通的不变量、过程层留痕与对账补偿
- [核心链路图.md](./基线文档/核心链路图.md) — 下单到配送签收的 Mermaid 链路图与时序图
- [部署手册.md](./基线文档/部署手册.md) — 环境要求、数据库初始化、前后端启动、Nginx 配置、小程序接入

## 实验（验证层）

- [实验环境与运行说明.md](./实验/实验环境与运行说明.md) — 实验库搭建、运行命令、结果查看、常见问题
