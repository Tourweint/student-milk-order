## 1. 测试概述

### 1.1 测试范围

- **功能测试**：覆盖认证、用户、班级学生、奶品配额、订单支付、配送、营养、可视化、自动续订、系统管理 10 个模块的核心链路与异常分支；
- **权限测试**：接口级角色控制（SecurityConfig）与服务层数据权限（Service 层收窄）两类规则的验证；
- **接口测试**：以 HTTP 接口为准（三端共用后端 `/api`），通过 curl / Postman / 自动化脚本执行；
- **性能冒烟**：单接口并发请求下的响应时间与稳定性初步观察（不作为验收硬指标，仅记录）。

### 1.2 不纳入范围

- 微信真实支付联调（本项目使用模拟器链路，上线前由部署方替换）；
- 小程序真机多机型适配（仅验证微信开发者工具 + 模拟支付链路）。

### 1.3 测试环境

| 项 | 值 |
|---|---|
| 操作系统 | Windows 10/11（开发机） |
| 数据库 | MySQL 8.x，库 `student_milk_order` |
| 后端 | Spring Boot 2.7.18 / Java 17，端口 8090 |
| 前端 | school-ui（Vite dev，端口 5173） |
| 小程序 | 微信开发者工具，`wechat.mock-enabled=true`（本地模拟 openid/支付） |
| 测试数据 | 预置 2 个年级、4 个班级、每班 20 名学生、3 个品类 8 个奶品、2 个学期套餐；账号：admin/123456、教师/配送站/家长各 1 个 |
