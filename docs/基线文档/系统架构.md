# 系统架构

## 技术栈

### 后端
- Java 17
- Spring Boot 2.7.18
- Spring Security（认证授权）
- MyBatis-Plus 3.5.3（数据访问）
- MySQL 8（数据库）
- JWT（无状态认证）
- Apache POI（Excel 导入导出）
- Spring Scheduler（定时任务）

### 前端（Web 管理端）
- Vue 3 + TypeScript
- Vite（构建工具）
- Element Plus（UI 组件库）
- ECharts（数据可视化）
- Axios（HTTP 客户端）
- Pinia（状态管理）
- Vue Router（路由）

### 移动端（微信小程序，后续开发）
- 微信小程序原生或 uni-app
- 共用后端 RESTful API

## 系统分层

```
┌─────────────────────────────────────────────┐
│              表现层 (Presentation)            │
│  Web 管理端 (Vue3)  │  微信小程序 (后续)      │
├─────────────────────────────────────────────┤
│              控制层 (Controller)              │
│         Spring Boot RESTful API              │
├─────────────────────────────────────────────┤
│              业务层 (Service)                 │
│     9 大业务模块的业务逻辑处理                │
├─────────────────────────────────────────────┤
│              持久层 (Mapper)                  │
│         MyBatis-Plus + MySQL                 │
└─────────────────────────────────────────────┘
```

## 业务模块划分

| 模块 | 说明 | 核心实体 |
|------|------|---------|
| 用户与权限 | 登录注册、RBAC 权限控制 | SysUser, SysRole, SysUserRole |
| 班级与学生 | 年级、班级、学生管理、Excel导入 | Grade, ClassInfo, Student |
| 奶品管理 | 品类、奶品、套餐、库存、预警 | ProductCategory, Product, MealPackage, Inventory |
| 订单核心 | 下单、支付模拟、状态流转、退订 | OrderInfo, OrderItem, PaymentRecord |
| 配送管理 | 配送任务、配送记录、签收 | DeliveryTask, DeliveryRecord |
| 营养统计 | 营养成分、摄入统计、报表 | NutritionInfo, NutritionIntake |
| 数据可视化 | 看板、趋势、排行、覆盖率 | （统计接口，无独立实体） |
| 月度自动续订 | 续订计划、定时任务 | SubscriptionPlan |
| 认证 | 登录、注册、当前用户 | （复用用户模块实体） |

## 部署架构

```
                    ┌──────────────┐
                    │   浏览器      │
                    │ (Web管理端)   │
                    └──────┬───────┘
                           │ HTTP
                    ┌──────▼───────┐
                    │  Nginx (80)  │  静态资源 + 反向代理
                    └──────┬───────┘
                           │ /api
                    ┌──────▼──────────┐
                    │ Spring Boot (8090)│  后端服务
                    └──────┬──────────┘
                           │ JDBC
                    ┌──────▼───────┐
                    │  MySQL (3306) │  数据库
                    └──────────────┘
```

## 订单状态机

```
待支付 ──支付──→ 已支付 ──开始配送──→ 配送中 ──签收完成──→ 已完成
  │                │                                        ↑
  └──取消/超时──→ 已退订 ←────────退订────────────────────┘
```
