# 部署手册

## 环境要求

- JDK 17+
- Maven 3.6+
- Node.js 16+
- MySQL 8.0+ 或 MariaDB 10.6+（本项目实测环境为 MariaDB 12.1）
- npm 或 pnpm

> **事务隔离级别**：数据源在 `application.yml` 中显式统一为 `READ_COMMITTED`
> （`spring.datasource.hikari.transaction-isolation`）。这是可靠性设计的一部分，不要改回
> `REPEATABLE READ`，否则 MariaDB 与 MySQL 对「快照建立后被并发修改的行」行为不一致
> （见 `可靠性设计.md` 第四、五节）。

## 数据库初始化

1. 创建数据库：
   ```sql
   CREATE DATABASE student_milk_order DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   ```

2. 执行建表脚本：
   ```bash
   mysql -u root -p student_milk_order < src/main/resources/sql/schema.sql
   ```

3. 执行初始数据：
   ```bash
   mysql -u root -p student_milk_order < src/main/resources/sql/data.sql
   ```

默认管理员账号：`admin / 123456`

> `data.sql` 含状态迁移规则种子（`state_transition_rule`）。状态机是**白名单语义**——缺规则会导致
> 所有状态迁移被拒绝，因此部署时不要跳过 `data.sql`。
>
> 若还需运行实验（`mvn test`），需另建结构相同的 `student_milk_order_test` 库，步骤见
> `../实验/实验环境与运行说明.md` 第 3 节。

## 后端启动

### 开发环境

```bash
# 进入项目根目录
cd student-milk-order

# 修改数据库配置
# 编辑 src/main/resources/application.yml，修改 datasource 的 url/username/password

# 编译
mvn clean compile

# 启动
mvn spring-boot:run
```

后端默认端口：`8090`

### 生产环境

```bash
# 打包
mvn clean package -DskipTests

# 运行
java -jar target/student-milk-order-1.0.0.jar
```

## 前端启动

### 开发环境

```bash
cd school-ui

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

前端默认端口：`5173`，已配置代理 `/api` → `http://localhost:8090`

### 生产环境

```bash
cd school-ui

# 构建
npm run build

# 构建产物在 dist/ 目录，部署到 Nginx 即可
```

## Nginx 配置示例

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态资源
    location / {
        root /path/to/school-ui/dist;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    # 后端 API 反向代理
    location /api/ {
        proxy_pass http://localhost:8090;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

## 多实例部署（可选）

系统设计上支持多实例（正确的来源是**幂等 + 唯一键 + 条件更新**，而不是分布式协调），
完整审计与未覆盖项见 `可靠性设计.md` 第十节。部署多实例时需满足：

| 要求 | 说明 |
| --- | --- |
| **实例必须校时（NTP）** | 超时判定、支付在途窗口、自动签收的"配送日期早于当天"都依赖本机时间；时钟不一致会让边界行为偏移 |
| **`wxpay.mock.notify-url` 必须指向负载均衡地址** | 当前默认值 `http://127.0.0.1:8090/...` 只适合单实例。支付状态已持久化，回调**落到哪个实例都能正确处理**，但指向不存在的实例端口时回调会全部失败（退化为纯对账补偿） |
| 定时任务**无需选主** | 6 个定时任务在每个实例都会触发，但写路径全部是 CAS / 唯一键 / 幂等跳过，重复执行只浪费算力不产生错误。若要省算力可自行加轻量选主（本项目未做） |
| 配置类变更最长 60 秒收敛 | 状态机规则、系统参数是每实例 60 秒 TTL 缓存，管理端改完在另一实例上可能最长 60 秒后生效 |
| 注册限频按实例独立 | 内存滑动窗口，N 个实例下等效阈值放大 N 倍（仅用于拦截脚本注册，非安全边界） |
| 数据库为唯一共享点 | 单库部署（无主从时最简）；若使用主从，注意对账/体检依赖读到的数据是**主库最新状态**，不要把这类任务路由到只读从库 |

Nginx 反向代理到多个后端实例：

```nginx
upstream milk_backend {
    server 127.0.0.1:8090;
    server 127.0.0.1:8091;   # 第二个实例（--server.port=8091）
}

server {
    listen 80;
    location /api/ {
        proxy_pass http://milk_backend;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```
