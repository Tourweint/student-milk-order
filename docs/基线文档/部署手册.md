# 部署手册

## 环境要求

- JDK 17+
- Maven 3.6+
- Node.js 16+
- MySQL 8.0+
- npm 或 pnpm

## 数据库初始化

1. 创建数据库：
   ```sql
   CREATE DATABASE student_milk_order DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   ```

2. 执行建表脚本：
   ```bash
   mysql -u root -p student_milk_order < src/main/resources/sql/schema.sql
   ```

3. 执行初始数据：
   ```bash
   mysql -u root -p student_milk_order < src/main/resources/sql/data.sql
   ```

默认管理员账号：`admin / 123456`

## 后端启动

### 开发环境

```bash
# 进入项目根目录
cd student-milk-order

# 修改数据库配置
# 编辑 src/main/resources/application.yml，修改 datasource 的 url/username/password

# 编译
mvn clean compile

# 启动
mvn spring-boot:run
```

后端默认端口：`8090`

### 生产环境

```bash
# 打包
mvn clean package -DskipTests

# 运行
java -jar target/student-milk-order-1.0.0.jar
```

## 前端启动

### 开发环境

```bash
cd school-ui

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

前端默认端口：`5173`，已配置代理 `/api` → `http://localhost:8090`

### 生产环境

```bash
cd school-ui

# 构建
npm run build

# 构建产物在 dist/ 目录，部署到 Nginx 即可
```

## Nginx 配置示例

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态资源
    location / {
        root /path/to/school-ui/dist;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    # 后端 API 反向代理
    location /api/ {
        proxy_pass http://localhost:8090;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```
