# 核心链路图

> 用 Mermaid 绘制项目核心路径：从下单到配送签收的完整链路、订单与配送任务的状态机。
> 在 GitHub/Gitea 等支持 Mermaid 的查看器中可直接渲染。

## 一、核心链路总览（按角色泳道）

```mermaid
flowchart TB
    subgraph P["家长 · 微信小程序"]
        A1["浏览奶品 / 学期套餐"] --> A2["创建订单（待支付）<br/>散订占当日机动配额预检"]
        A2 --> A3["微信支付（模拟）"]
        A9["退订 / 取消支付<br/>（仅未开始配送可退）"]
    end

    subgraph S["系统 · 支付成功事务内自动联动"]
        B1["写支付流水"] --> B2["订单 → 已支付"]
        B2 --> B3["展开整期配送任务 + 签收记录<br/>散订 1 天 / 学期套餐约 153 天"]
        B3 --> B4["散订按品种原子扣减当日机动配额<br/>（学期套餐不占配额）"]
    end

    subgraph D["配送站 · Web 面板（DELIVERY / ADMIN）"]
        C1["查看今日概览<br/>应送 / 待配送 / 已送出 / 已签收"]
        C1 --> C2["今日已送出（批量开始配送）<br/>记录派送人 + 派送时间"]
        C2 --> C3["🔒 退款闸门：订单联动 → 配送中<br/>此后不可自助退订"]
        C4["查询任务（日期区间 / 订单号）<br/>签收情况只读"]
    end

    subgraph T["班主任 · Web 管理端（TEACHER，限本班）"]
        E1["查看本班待签收记录"] --> E2["签收 / 批量签收<br/>（仅可签已送出的任务）"]
        E2 --> E3["拒收（任务 → 已取消）"]
    end

    subgraph N["系统 · 签收事务内自动联动"]
        F1["签收记录 → 已签收"]
        F2["任务 → 已完成<br/>按每100ml营养成分生成营养摄入记录"]
        F3["订单下任务全部终态<br/>→ 订单自动完成"]
        F1 --> F2 --> F3
    end

    A2 --> S
    A3 --> S
    A9 -. "退订：作废未开始任务<br/>散订回补配额" .-> S
    B3 --> C1
    C3 --> E1
    E2 --> N
    E3 --> N
    C2 -. "拒收/取消任务也计入终态" .-> F3
```

## 二、核心路径时序图（含退款闸门与自动完成）

```mermaid
sequenceDiagram
    autonumber
    actor Parent as 家长（小程序）
    participant Sys as 后端（事务内联动）
    actor Station as 配送站（DELIVERY/ADMIN）
    actor Teacher as 班主任（TEACHER，限本班）

    Parent->>Sys: 创建订单（散订单日 / 学期套餐）
    Sys-->>Parent: 待支付（散订做配额预检）
    Parent->>Sys: 发起支付（模拟微信回调）
    Sys->>Sys: 写支付流水 + 订单→已支付<br/>展开整期任务与签收记录 + 散订扣配额
    Note over Sys: 此时可退订：散订按台账回补配额，<br/>未开始任务作废

    Parent->>Sys: 退订？
    alt 任务尚未开始配送
        Sys-->>Parent: 退订成功（任务作废 + 配额回补）
    else 配送站已点击"今日已送出"
        Sys-->>Parent: 拒绝：已开始配送，请联系管理员线下处理
    end

    Station->>Sys: 今日已送出（按日期批量开始配送）
    Sys->>Sys: 任务→配送中，记录派送人/派送时间<br/>订单→配送中（🔒 退款闸门生效）
    Station->>Sys: 查看签收情况（只读）

    Teacher->>Sys: 签收 / 批量签收（仅限已送出任务）
    Sys->>Sys: 签收记录→已签收，任务→已完成<br/>生成营养摄入记录
    alt 该订单任务全部到达终态
        Sys->>Sys: 订单自动→已完成
    end
    Teacher->>Sys: 拒收（可选，任务→已取消）
```

## 三、订单状态机

```mermaid
stateDiagram-v2
    [*] --> 待支付1: 创建订单
    待支付1 --> 已支付2: 支付成功（写流水+展开整期任务）
    已支付2 --> 配送中3: 任务开始配送联动（退款闸门🔒）
    配送中3 --> 已完成4: 任务全部终态自动完成 / 管理员手动完成
    待支付1 --> 已退订5: 取消支付
    已支付2 --> 已退订5: 退订（散订回补配额+作废未开始任务）
    note right of 已支付2
        退款闸门：存在配送中任务
        或订单已配送中时不可退订
    end note
    note right of 已完成4
        开始配送后的退费一律走线下
    end note
```

> 状态码：1 待支付、2 已支付、3 配送中、4 已完成、5 已退订

## 四、配送任务状态机

```mermaid
stateDiagram-v2
    [*] --> 待配送1: 支付成功展开整期任务
    待配送1 --> 配送中2: 开始配送（单条/今日已送出）<br/>记录派送人+派送时间
    配送中2 --> 已完成3: 班主任签收（生成营养摄入）
    配送中2 --> 已取消4: 拒收 / 管理员取消
    待配送1 --> 已取消4: 订单退订联动作废 / 管理员取消
    note right of 配送中2
        签收/拒收仅允许在此状态：
        未送出的任务不可签收
    end note
```

> 状态码：1 待配送、2 配送中、3 已完成、4 已取消；签收状态：1 已签收、2 未签收、3 拒收

## 五、角色与权限速查

| 角色 | 数据范围 | 核心操作 |
|------|----------|----------|
| ADMIN（管理员） | 全部 | 全部管理功能 + 配送任务操作（开始配送/取消/补生成）+ 代签 |
| DELIVERY（配送站） | 全部（仅配送接口） | 查看任务/今日概览、"今日已送出"、单条开始配送；签收情况只读 |
| TEACHER（班主任） | 仅本班 | 签收/批量签收（仅已送出任务）、拒收、本班学生与订单管理 |
| PARENT（家长） | 仅绑定学生 | 下单、支付、退订（未开始配送时）、查看订单/配送/营养 |
