# 2026-09-12 权限细节收紧（订单状态机角色限制 + 注册限频 + 班级下拉过滤）

## 变更背景

在「2026-09-12 权限管理收紧」基础上，按 curl 直连视角复核后发现并处理三处细节：

1. **订单状态机无角色限制**：`PUT /api/order/deliver/{id}`、`PUT /api/order/complete/{id}` 只做归属校验（是本人/本班的订单），未限制角色。家长 token 可给自己孩子的订单调「开始配送/完成订单」，越过家长职责边界（水平越权已挡、垂直未挡）。小程序家长端实际只调用 list/detail/create/pay/cancel，不受影响。
2. **注册接口无频率限制**：`/auth/register` 公开且不限制频率，存在被脚本批量刷号的风险。评估结论：保留公开注册（家长自助注册仍有用），只加 IP 维度频率限制。
3. **班级下拉未按角色过滤**：`GET /api/clazz/class/list`、`GET /api/clazz/class/all` 对所有 Web 角色返回全部班级，班主任下拉可见全校班级（选择其他班虽被后端强制收窄、不泄露数据，但交互困惑）。该接口被订单页、配送页、学生页下拉共用。

## 变更内容

### 后端

- `config/SecurityConfig`：新增接口级角色规则——`PUT /api/order/deliver/**`、`PUT /api/order/complete/**` 仅 ADMIN、TEACHER（家长不可代跑配送流程）。规则表更新见接口文档。
- 新增 `common/ratelimit/RegisterRateLimiter`：内存滑动窗口限频组件。规则：同一 IP 60 秒内最多 1 次注册、1 小时内最多 5 次，超限抛 `BusinessException(429)`；`@Scheduled` 每天凌晨 3 点清理过期记录，防止内存累积。
- `module/auth/service/impl/AuthServiceImpl`：`register` 入口调用 `registerRateLimiter.check(resolveClientIp())`，IP 取自 `RequestContextHolder`（无请求上下文时放行）。
- `module/clazz/service/impl/ClassInfoServiceImpl`：注入 `DataScopeResolver`；`pageClasses`、`listAll` 增加数据权限——班主任仅返回本班（`classId`），管理员不限。
- `module/clazz/service/impl/StudentServiceImpl`：`pageStudents` 由 `resolve()` 改为 `resolveQuietly()`，修复 2026-09-12 权限收紧引入的回归——免认证的 `bind-student/search` 内部走 `pageStudents`，原实现未登录直接抛 401，导致小程序绑定流程按学号/姓名搜索孩子失败；列表接口本身有网关层登录/角色保证，改后安全等价（未登录仅放行公开绑定搜索，已登录行为不变）。

### 文档

- `docs/基线文档/接口文档.md`：接口级角色控制表新增订单状态机规则行；`/clazz/class/list`、`/clazz/class/all` 补充数据权限说明；数据权限表 TEACHER 行补充班级列表与下拉；`/auth/register` 条目补充限频说明；错误码表新增 429。

## 验证结果

- `mvn clean compile` 通过；前端无改动。
- 接口冒烟验证（在 8091 调试实例，含最新源码，2026-09-12 14:1x 完成）：

| 用例 | 请求 | 预期 | 实际 | 结果 |
| --- | --- | --- | --- | --- |
| 注册限频 | `POST /api/auth/register`（同 IP 连发两次） | 第 1 次 200，第 2 次 429 | 200 → `429 注册过于频繁，请稍后再试` | 通过 |
| 订单状态机-家长 | 家长 token `PUT /api/order/deliver/1`、`PUT /api/order/complete/1` | 403 | HTTP 403 + `403 权限不足` | 通过 |
| 订单状态机-教师 | 教师 token `PUT /api/order/deliver/1` | 过网关（非 403） | 进入业务逻辑，返回 `500 仅已支付订单可开始配送` | 通过 |
| 班级下拉-教师 | 教师 token `GET /api/clazz/class/all` | 仅本班 | 仅返回「一年级1班」1 条 | 通过 |
| 班级下拉-管理员 | 管理员 token `GET /api/clazz/class/all` | 全部 | 返回全部 17 个班级 | 通过 |
| 学生列表-教师 | 教师 token `GET /api/clazz/student/list` | 仅本班 | 6 条均为 class_id=1 | 通过 |
| 越权兜底-教师 | 教师 token `GET /api/user/list` | 403 | `403 权限不足` | 通过 |
| 绑定搜索回归 | 免认证 `GET /api/auth/bind-student/search?keyword=20240101` | 200 | 返回张小明（class 一年级1班） | 通过 |

- 家长端读接口不受影响：家长 token `GET /api/product/list` 仍返回 200。
- 测试数据（wx-bind 家长账号、注册测试账号）验证后已用管理员接口删除。
- 注意：8090 运行中的实例仍加载旧编译产物，新规则需重启后生效；上述验证均在 8091 调试实例完成。

## 遗留与注意事项

1. `GET /api/clazz/class/{id}`（班级详情）未按角色过滤，班主任可查看其他班详情（班级名/年级/班主任，非敏感数据）；如需彻底一致可后续补充。
2. 注册限频为单机内存实现：重启清空计数；若后续多实例部署需换 Redis 等共享存储。
3. `GET /api/product/**` 模块级放行（家长/教师可读库存、流水，`ProductVO` 含成本价）与 `POST /api/subscription/trigger/{id}` 手动续订入口维持现状，未在本轮处理（评估风险可接受或已确认保留）。
