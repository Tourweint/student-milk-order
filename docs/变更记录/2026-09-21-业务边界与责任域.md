# 2026-09-21 业务边界与责任域文档新增

## 背景

围绕"系统复用（移动给其他学校/中间商使用）"与真实配送模式的讨论，需要一份统一的
**业务边界**裁决依据：系统覆盖业务链的哪一段、刻意不建什么及理由。本文档即该讨论的
落地成果，供后续需求评审、待办项判定与答辩口径使用。

## 关键业务事实确认（2026-09-21 与业务方确认）

- 奶企送到学校**公共领取点**，但**学校配送站已按班级分类**（一箱/一筐一班），学生只承担
  "走路取走本班份"的搬运动作——即"**逻辑送班**"，班级粒度成立，配送任务按班级展开的现状不变。
- 确认环节是"**事后核对**"而非"当场清点"：大课间学生取奶 → 回班自发分发 → 有人没拿到会找
  班主任 → 搬奶同学说明 → 班主任当天能确认本班实际领走几盒。"签收即视为饮用"口径成立。
