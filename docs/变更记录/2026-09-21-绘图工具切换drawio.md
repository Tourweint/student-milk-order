# 2026-09-21 绘图工具切换：PlantUML(Java 渲染) → draw.io

## 背景与动机

- 项目图件此前两条线：`docs/基线文档/UML/`（用例图/类图/部署图）用 PlantUML，渲染要装 Java + `plantuml.jar`；
  `docs/基线文档/核心链路图.md` 用 Mermaid（GitHub 直接渲染）。
- PlantUML 默认皮肤效果粗糙（评审/答辩观感差），且 `*.png` 自 2026-09-15 后未重新渲染已过期；
  Java 渲染链路重、改图门槛高。
- 结论：**图件统一切到 draw.io（`*.drawio`，mxGraph XML）**。XML 是纯文本、可 diff、可复现，
  draw.io 生态成熟（Desktop / VS Code / app.diagrams.net 均可编辑），AI 生成质量与可维护性更好。
  文档内嵌小图继续用 Mermaid（渲染零成本），不迁移。

## MCP 选型（本次实测）

| 候选 | 结论 | 依据 |
|---|---|---|
| **官方 `@drawio/mcp`（jgraph/drawio-mcp）** | ✅ **采用** | 实机探测 `drawio-mcp v1.6.0`，7 工具：`open_drawio_xml/csv/mermaid`、`list_pages`、`get_page`、`set_page`、`search_shapes`；`search_shapes` 覆盖官方 1 万+ 形状库；本地 stdio 运行、无外部数据出域 |
| `lgazo/drawio-mcp-server` | ❌ 弃用 | 首次启动需联网下载 draw.io 资源（本机直接 `ECONNRESET`），且依赖常开本地编辑器页 + WebSocket，不适合无人值守 |
| 无 MCP 直写 XML | 保留为兜底 | MCP 不可用时手写 mxGraph XML，配合 draw.io 打开验证 |

接入方式（AutoClaw 桌面端）：

- `node D:\autoClaw\resources\gateway\openclaw\openclaw.mjs mcp add drawio --command npx --arg -y --arg "@drawio/mcp"`
  → 写入 `~\.openclaw-autoclaw\openclaw.runtime.json`（`mcp.servers.drawio`）。
- `search_shapes` 的形状索引默认从 `raw.githubusercontent.com` 下载，本机网络不通；
  已在注册项补 `env.DRAWIO_SHAPE_INDEX_URL=https://gh-proxy.com/https://raw.githubusercontent.com/jgraph/drawio-mcp/main/shape-search/search-index.json`（镜像实测 4.77MB 可下载），并设同名用户级环境变量兜底。
- `config.patch` 对 `mcp.servers.*` 是保护路径，MCP 注册必须走 CLI（`openclaw mcp add/set`），改 env 后需重启 gateway 生效。
