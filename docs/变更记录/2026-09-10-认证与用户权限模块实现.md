# 2026-09-10 认证与用户权限模块实现

## 变更背景

骨架搭建完成后，按既定顺序（认证 → 班级学生 → 奶品 → 订单…）开始填充业务逻辑。首个实现的是认证与用户权限模块（auth/user），它是所有模块的地基。

## 变更内容

### 后端

1. **认证模块（auth）**：
   - 新增 `AuthService` / `AuthServiceImpl`：实现登录（BCrypt 校验 + JWT 生成）、注册（创建用户 + 分配角色）、获取当前用户
   - 实现 `AuthController` 三个接口：`POST /api/auth/login`、`POST /api/auth/register`、`GET /api/auth/me`

2. **用户模块（user）**：
   - 新增 `SysUserRoleService` / `SysUserRoleServiceImpl`：查询用户角色编码
   - `SysUserService` 增加：`getByUsername`、`isUsernameExists`、`pageUsers`（关键词分页查询）
   - 实现 `UserController`：
     - `GET /api/user/list` 分页查询（关键词模糊匹配用户名/姓名/手机号）
     - `GET /api/user/roles` 角色列表（下拉选择用）**【新增接口】**
     - `GET /api/user/{id}` 用户详情（返回 UserVO，不含密码）
     - `POST /api/user` 新增用户（BCrypt 加密 + 分配角色）
     - `PUT /api/user` 修改用户（含角色变更）
     - `DELETE /api/user/{id}` 删除用户（级联删角色关联）
     - `PUT /api/user/{id}/password` 重置密码 **【新增接口】**
   - 新增 DTO：`UserSaveRequest`、`UserUpdateRequest`、`UserResetPasswordRequest`
   - 新增 VO：`UserVO`（脱敏，不含密码字段）

3. **数据修正**：
   - `data.sql` 中 admin 密码 hash 为无效占位值，重新生成对应 `123456` 的 BCrypt hash 并更新

### 前端

1. **用户管理页面** `UserManage.vue` 完整实现（简约风格）：
   - 关键词搜索 + 重置
   - 用户表格（用户名/姓名/角色标签/手机号/状态/创建时间/操作）
   - 新增/编辑对话框（含角色下拉、状态单选）
   - 重置密码对话框
   - 删除确认
   - 分页
2. **API 封装** `api/user.ts` 增加：`getRoleList`、`resetPassword`
3. 登录页此前已对接真实登录接口，本次验证通过

## 影响范围

- 后端：auth、user 两个模块的 controller/service 层；`docs/基线文档/接口文档.md` 需补充 2 个新增接口
- 前端：`UserManage.vue`、`api/user.ts`
- 数据库：`data.sql` 的 admin 密码 hash
