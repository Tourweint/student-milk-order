# 变更记录：订购模式重构（学期套餐 + 每日机动配额，下线月度套餐与传统库存）

- 日期：2026-09-12
- 范围：后端 product/order/stats 模块、管理端、小程序、数据库

## 新业务模型

1. 订购模式仅两种：
   - **学期套餐（主业务）**：全校统一预约定制订单，配送周期固定约 5 个月。支付成功后自动展开全学期每日供奶计划（每日每奶品一条任务+签收记录）。**不参与任何库存/配额扣减，全程与库存无关**。
   - **单日零散订购（辅助小众业务）**：起止同日、按盒数一次性配送，**占用当日机动配额**。用于临时补订、换口味、插班临时订购，卖完即止。
2. **每日机动配额**（`daily_quota` 表）替代全部传统库存概念：管理员按日手动设置当日可售机动盒数；零散订购在支付事务内原子扣减、退订回补；未设置配额的日期不可零散订购。
3. **配额结转与保质期**：当日未售完的机动配额自动结转次日继续可售；按 3 天保质期滚动，窗口外剩余自动作废（动态计算，无需定时任务）；扣减"先卖最老的池子"，台账 `daily_quota_usage` 按订单记录各池子扣减明细，退订精确回补。
4. 业务隔离（学期覆盖日禁散订）经用户确认**已取消**：学期套餐家长同样可以单日散订换口味/加购，仅受当日余量约束。
4. **月度套餐彻底下线**，自动续订功能随之下线（学期套餐为一次性购买）；传统库存/入库出库/盘点/库存预警全部移除。

## 后端

- 新增 `DailyQuota` 实体/`DailyQuotaService`（原子扣减 `deduct`/回补 `restore`/余量查询）及接口：`GET /product/quota/list`、`GET /product/quota/remaining`、`PUT /product/quota`（ADMIN）。
- 删除库存体系：Inventory/InventoryRecord 实体与 Mapper、InventoryService、库存预警定时任务、库存相关 DTO/VO/枚举、ProductController 库存接口。
- 订单链路：散订强制单日（起止同日）+ 学期覆盖防重复校验 + 下单预检/支付扣减/退订回补配额；学期套餐不扣任何配额。
- 奶品 ProductVO 移除 `quantity` 字段；奶品增删不再初始化/清理库存。
- 套餐保存强制 packageType=2（仅学期）；看板"库存预警"指标改为"今日机动余量"。

## 管理端

- "库存与流水"页签替换为"每日机动配额"（按日设置/调整配额，展示已售与剩余）。
- 奶品列表移除库存列；看板指标卡改为"今日机动余量"；移除"自动续订"菜单与路由。

## 小程序

- 奶品页/首页移除库存展示，改为配额提示；下单页（散订）展示所选日期"当日机动余量"；"我的"页移除自动续订入口。

## 数据库

- 新增 `daily_quota` 表（quota_date 唯一）；删除 `inventory`、`inventory_record` 表。
- 套餐重建为 3 个学期套餐（纯牛奶/酸奶/混合，固定明细同步）；存量月度续订计划全部下线。
