# 变更记录：套餐内容固定化（家长不可自选奶品）

- 日期：2026-09-12
- 范围：后端 product/order 模块、管理端套餐管理、小程序下单页

## 背景

此前套餐下单要求家长自选"奶品明细（数量×盒数）"，但套餐金额是固定打包价、与明细数量不联动，家长可以用套餐价订出任意大的每日数量（资损口子），且"添加奶品"语义含糊。决策：套餐内容固定，由管理端配置；家长想喝其他口味走散订（次日配送）。

## 设计

- 复用既有 `meal_package_item` 表（套餐 ID + 奶品 ID + 每日数量）作为套餐固定配置，此前从未在运行时使用。
- 套餐订单的订单明细一律以服务端套餐配置为准（服务端权威），忽略客户端传入明细；套餐未配置明细时禁止下单。
- 管理端新增/编辑套餐时必须配置固定明细（至少一种奶品，每日数量 ≥1）；修改时明细整体替换；删除套餐时清理明细。

## 变更内容

### 后端

1. `GET /product/package/{id}` 改为返回 `MealPackageDetailVO`（套餐字段 + `items[{productId, productName, spec, quantity}]`）。
2. `POST/PUT /product/package` 改为接收 `PackageSaveRequest`（原字段不变 + 必填 `items`），`@Valid` 校验；明细中奶品须存在。
3. `DELETE /product/package/{id}` 联动清理固定明细。
4. `OrderInfoServiceImpl.doCreateOrder`：套餐订单明细从 `meal_package_item` 读取，忽略客户端传入。

### 管理端

- 套餐管理（PackageTab）表单新增"配送明细"编辑：多选奶品 + 逐项每日数量；编辑时回显已有配置。

### 小程序

- 下单页套餐模式：明细改为只读展示（"套餐包含（每日配送）"，每项显示"每日 N 盒"），移除"添加奶品"自选区；页面提示"套餐内容固定不可自选；想喝其他口味可用散订单独购买，次日配送"。

## 遗留说明

- 套餐价格与明细数量仍不联动（打包价模式），管理端编辑页有提示文案；如需按明细计价再另行设计。
- 已有种子套餐（纯牛奶月度/酸奶月度/混合月度/纯牛奶学期）的固定明细已在 `meal_package_item` 中配置。
