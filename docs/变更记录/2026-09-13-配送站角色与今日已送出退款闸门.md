# 变更记录：配送站角色、"今日已送出"与退款闸门

- 日期：2026-09-13
- 范围：后端 delivery/order/config 模块、管理端、数据库、文档

## 背景与决策

配送链路此前存在两个缺口：

1. **退款闸门挂错位置**：配送站日常只点任务级"开始配送"，订单级"开始配送"按钮（订单管理页）无人点击；任务已"配送中"而订单仍是"已支付"时，家长仍可退订，且退订会把配送中的任务一并作废、回补配额（奶已送出却完成退订）。
2. **无派送审计痕迹**：任务从待配送变为配送中不记录操作人与时间。

经确认的决策：

- 退款闸门挂在配送站"今日已送出"动作上：任务开始配送（单条或批量）即联动订单进入配送中，此后不可自助退订。
- 学期套餐与散订一致：开始配送后整单不可自助退费，退费走线下处理，系统不做按天折算。

## 新增

- **DELIVERY（配送站）角色**：`sys_role` 新增 id=4；示例账号 `delivery / 123456`。数据范围为全部数据，但接口层仅开放：配送任务查询/单条开始、"今日已送出"批量开始、配送记录**只读**。不可补生成/取消任务、不可签收/拒收、不可退订或修改任何业务数据。`DataScopeResolver` 中 DELIVERY 不限范围（接口层已收窄）。
- **配送站面板**（`/delivery-station`，ADMIN/DELIVERY）：配送日期切换；按班级汇总应送/待配送/已送出/已签收/已取消；"今日已送出"一键批量开始配送；任务明细支持**日期区间 + 订单号**筛选（解决跨月学期订单只能看单日的问题）并展示派送人/派送时间；签收情况只读列表。

## 后端

- `PUT /api/delivery/task/batch-start`（ADMIN/DELIVERY）：按日期（可选班级）批量开始配送，仅对"待配送"任务生效（幂等），逐条写 `dispatch_by`/`dispatch_time`，并联动涉及订单已支付→配送中，返回开始条数。
- `GET /api/delivery/task/summary`：某配送日期按班级汇总任务状态数量（含班级名，配送站无需班级管理权限）。
- `GET /api/delivery/task/list` 新增 `dateEnd`（与 deliveryDate 组成日期区间）与 `orderNo`（订单号模糊）筛选；回填派送人/派送时间。
- 任务单条开始配送同样记录派送人/时间并联动订单（`OrderInfoService.markDeliveringIfPaid`，状态机统一出口；DeliveryTaskServiceImpl 以 `@Lazy` 注入打破循环依赖）。
- 退订保险：`cancelOrder` 除状态校验外，若订单存在"配送中"任务（`hasDispatchingTask`）同样拒绝退订，防止漏点订单级开始配送或并发场景下退掉已送出的奶。
- `pageTasks` 补充数据权限：班主任强制限定本班（此前可看全部班级，与规范不符）；管理员/配送站不限。
- `SecurityConfig`：`/delivery/task/generate`、`/delivery/task/cancel/**` 限 ADMIN/TEACHER；`/delivery/task/batch-start` 与 `/delivery/task/start/**`（单条开始）限 ADMIN/DELIVERY；其余任务接口 ADMIN/TEACHER/DELIVERY；`POST /delivery/record/**`（签收/拒收）保持 ADMIN/TEACHER；`/api/order/**` 限 ADMIN/TEACHER/PARENT（配送站不接触订单数据）。
- 下线订单级 `PUT /order/deliver/{id}` 接口与 `OrderInfoService.startDelivery`：订单回归订单，"开始配送"由配送任务（单条或"今日已送出"）联动触发，即退款闸门；订单管理页同步移除"开始配送"按钮。
- **订单自动完成**：订单下配送任务全部到达终态（已完成/已取消）时自动将配送中订单流转为已完成（`completeOrderIfAllTasksDone`，在签收/拒收/取消任务事务内触发）；`PUT /order/complete/{id}` 保留为手动提前完成入口。
- **签收/拒收前置校验**：仅可对已开始配送（配送中）的任务签收/拒收；批量签收只处理已送出任务的记录，杜绝"奶未送出先签收"导致订单与配送状态脱节。

## 管理端

- 新增配送站面板页面与菜单（`Box` 图标）；数据看板/班级/学生/订单/配送/营养菜单与路由补充 `roles: ['ADMIN','TEACHER']`，配送站登录后仅见配送站面板。
- 路由守卫角色不满足时回退到"当前用户有权访问的第一个菜单页"（此前硬编码 /dashboard，会对配送站形成回退死循环）。
- 用户管理的角色展示映射补充 DELIVERY（角色下拉本就取自 `sys_role` 表，无需改动）。
- 配送站面板样式与各管理页对齐（根节点 20px 内边距）；配送管理任务页"开始配送"按钮仅管理员可见（班主任只读+签收）。

## 数据库

- `delivery_task` 新增 `dispatch_by VARCHAR(50)`、`dispatch_time DATETIME`（存量库执行：`ALTER TABLE delivery_task ADD COLUMN dispatch_by VARCHAR(50) COMMENT '派送操作人（用户名，开始配送时记录）', ADD COLUMN dispatch_time DATETIME COMMENT '派送时间（开始配送时记录）';`）。
- `delivery_person_id` 为历史遗留未使用字段，保持不动。
- `data.sql` 新增 DELIVERY 角色与 delivery 示例账号。
