# 2026-09-17 配送签收自动兜底与提醒（A/B/C 三层方案）

## 变更背景

班主任（老师）经常忘记点击「已签收」，导致已送出的配送任务长期停在「配送中」：订单无法自动完成、营养摄入记录不生成、数据看板统计缺失。配送站点击「今日已送出」有动力且简单，签收却完全依赖老师当天主动操作，没有兜底。

方案（用户确认）：**A 自动签收兜底（治本）+ B 当天提醒 + C 一键入口前置**。拒收是老师当场的即时人工动作且很少发生，自动兜底只处理「已送出 + 未签收 + 未拒收」记录，不会误伤。

## 核心设计决策

1. **自动签收兜底（A）**：定时任务每天 00:30 扫描「配送日期早于当天 + 任务已送出（配送中）+ 记录未签收」的配送记录，复用人工签收共用流程 `doSign`（状态机 CAS 配送中→已完成、生成营养摄入、订单全终态自动完成），签收人标记「系统自动签收」。兜底窗口为配送日期早于当天——当天送出的留给老师当天签收，不自动兜底。
2. **逐条独立事务**：定时任务逐条调用 Service 单条自动签收方法（独立事务、幂等、静默跳过已处理），单条失败不影响其余，避免历史脏数据拖死整批。
3. **待签收汇总（B/C 数据源）**：新增 `GET /delivery/record/pending-sign`，某日期（默认今天）已送出未签收记录按班级聚合，班主任数据范围强制限本班，管理员/配送站全量。
4. **入口前置（C）**：配送记录页默认日期=今天并显示「今日待签收 X 条 + 一键签收」提示条（复用批量签收接口）；数据看板展示今日待签收指标（`DashboardVO.pendingSignCount`）并点击跳转配送记录页。
5. **配送站提醒（B）**：配送站面板顶部展示「已送出未签收」总数提醒（配送站与老师线下接触最多，口头提醒最有效），复用现有 summary 数据，无新接口。

## 变更内容

### 后端（delivery 模块）

- **VO**：新建 `PendingSignVO`（total + 按班级聚合 `classes:[{classId,className,count}]`）
- **Service**：`DeliveryTaskService` 新增 3 方法
  - `listExpiredAutoSignRecordIds(limit)`：自动签收候选（配送日期<今天 + 任务配送中 + 记录未签收，单批上限 200）
  - `autoSignOne(recordId)`：单条自动签收（独立事务、幂等、静默跳过不满足前置条件的记录，复用 doSign）
  - `pendingSign(deliveryDate)`：待签收汇总（班主任限本班，按班级聚合按条数降序）
- **Job**：新建 `DeliveryAutoSignJob`，`@Scheduled(cron = "0 30 0 * * ?")` 每天 00:30 执行，逐条 try-catch 调用 `autoSignOne`
- **Controller**：`GET /api/delivery/record/pending-sign`（所有登录角色可读，数据范围 Service 层控制）

### 后端（stats 模块）

- `DashboardVO` 新增 `pendingSignCount`（今日待签收配送记录数，班主任限本班、管理员全量）；`StatsServiceImpl` 注入 delivery mapper 统计

### 前端

- `api/delivery.ts`：新增 `getPendingSign`
- `Dashboard.vue`：今日待签收 > 0 时显示警示横幅，点击跳转 `/delivery?tab=record`
- `DeliveryManage.vue`：支持 `?tab=record` 直达配送记录页
- `DeliveryRecordTab.vue`：配送日期默认今天；顶部「今日待签收 X 条（班级明细）+ 一键签收今日」提示条；批量签收支持指定日期
- `DeliveryStation.vue`：顶部「已送出 X 条尚未签收」提醒条（配送站提醒班主任）

### 环境修复（顺带）

- `school-ui` 的 typescript 被 `^5.3.3` 漂移到 5.9.3，与 vue-tsc 1.8.27 不兼容导致 `npm run build` 中 vue-tsc 直接崩溃；钉回 `typescript@5.3.3`（--save-exact）后类型检查恢复
- 修复存量类型错误：`request.ts` 泛型断言（axios 版本间签名不一致）、`NutritionInfoTab.vue` productId 收窄、`StudentManage.vue` UploadRawFile 类型
- 删除无引用的遗留死代码 `InventoryTab.vue`（引用的库存 API 不存在，后端无库存概念——系统以「每日机动配额」替代传统库存，该组件未被任何页面引用且会导致 vite 打包 named export 错误）

## 影响范围

- 后端：delivery 模块（VO/Service/Job/Controller）+ stats 模块（DashboardVO/StatsServiceImpl）
- 前端：Dashboard、DeliveryManage、DeliveryRecordTab、DeliveryStation、api/delivery.ts
- 数据库：表结构无变化（自动签收复用 sign_person/remark 字段标记，不新增字段）
- 定时任务：新增 DeliveryAutoSignJob（每天 00:30）

## 验证结果

- 后端 `mvn clean compile` 通过、`mvn test` 通过
- 前端 `npm run build`（vue-tsc + vite build）通过
- 自动签收口径：只处理「配送日期 < 今天 + 任务配送中 + 记录未签收」；当天送出留给老师当天签收；拒收（即时人工动作）不受影响
