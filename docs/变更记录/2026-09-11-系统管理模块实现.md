# 2026-09-11 系统管理模块实现（角色查看 + AOP 操作日志）

## 变更背景

按模块顺序实现第九个（最后一个）模块——系统管理（system）。包含两块：角色管理（查看系统内置三种角色）和操作日志（AOP 自动记录所有写操作）。

## 核心设计决策

1. **角色只查看不增删**：系统内置 ADMIN/TEACHER/PARENT 三种角色，权限在 SecurityConfig 中硬编码。在线增删角色会导致权限配置不同步，因此角色管理只做列表查看。
2. **AOP 自动记录操作日志**：用 `@Aspect` 切面拦截所有 `@RestController` 的方法，只记录写操作（POST/PUT/DELETE），GET 不记录（避免日志量过大）。无需在每个方法上加注解，零侵入。
3. **日志记录内容**：操作用户、操作描述（根据URL+HTTP方法自动生成，如"新增 - product"、"支付 - order"）、请求URL、HTTP方法、类名.方法名、请求参数（JSON，密码自动脱敏）、客户端IP（支持 X-Forwarded-For）、耗时、状态（成功/失败）、异常信息。
4. **登录日志特殊处理**：登录接口在 Security 过滤链之前，SecurityContext 未建立，username 记为 "anonymous"。
5. **日志保存失败不影响业务**：切面中日志保存用 try-catch 包裹，保存失败只记 error 日志，不影响主流程。

## 变更内容

### 数据库

- schema.sql 新增 `operation_log` 表（21 张表）
- 字段：id, user_id, username, operation, method, request_url, request_method, request_params, ip, cost_time, status, error_msg, create_time
- 索引：user_id, create_time, status

### 后端

- **pom.xml**：新增 `spring-boot-starter-aop` 依赖
- **entity**：`OperationLog`（独立实体，不继承 BaseEntity，因为表无 update_time/deleted）
- **mapper**：`OperationLogMapper`
- **service**：`OperationLogService` + `OperationLogServiceImpl`（分页+多条件筛选：用户名/状态/时间范围）
- **controller**：`SystemController`，2 个接口（角色列表、操作日志分页）
- **aspect**：`OperationLogAspect`（AOP 切面，核心组件）
  - `@Around("within(@RestController *)")` 拦截所有 Controller
  - 只记录 POST/PUT/DELETE
  - 密码字段正则脱敏
  - 异常时记录 error_msg 并重新抛出

### 前端

- `api/system.ts`：新建（getRoleList、getOperationLogList）
- `SystemManage.vue`：重写为两个 tab
  - 角色管理：表格展示 3 个角色（编码/名称/描述/排序/状态）+ 提示说明
  - 操作日志：筛选（用户名/状态/时间范围）+ 分页表格 + 详情抽屉（含请求参数和异常信息展示）

## 影响范围
