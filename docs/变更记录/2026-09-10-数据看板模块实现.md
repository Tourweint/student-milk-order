# 2026-09-10 数据看板模块实现（统计接口 + ECharts 可视化）

## 变更背景

按模块顺序实现第七个模块——数据看板（stats）。前端 Dashboard.vue 骨架已有完整布局和模拟数据，本模块把后端统计接口补齐，并把前端模拟数据替换为真实接口数据。

## 核心设计决策

1. **统计在 Java 层聚合**：所有统计（趋势分组、品类占比、班级排行、覆盖率）都查出原始数据后在 Java 层用 Stream 分组求和，不写复杂 SQL group by，可读性和可维护性更好。
2. **趋势连续日期补零**：order/trend 生成连续的日期/月份标签，没有订单的日期补 0，保证折线图 X 轴连续不跳变。
3. **营养仪表盘复用 nutrition_intake**：直接读配送签收时写入的 nutrition_intake 表，统计总摄入和平均每日每生摄入，不重复计算。
4. **覆盖率按班级拆分**：总覆盖率 + 各班级覆盖率（在订学生数/总学生数），便于横向对比。

## 变更内容

### 后端

- **VO**：`DashboardVO`（4个指标）、`TrendVO`（dates/orderCounts/sales）、`ClassRankingVO`（班级/订单数/销售额）、`CoverageVO`（总比率+各班级 ClassCoverage 列表）
- **Service**：新建 `StatsService` 接口 6 方法 + `StatsServiceImpl` 完整实现
  - `dashboard`：订单总数、在订学生数（有效订单去重）、本月销售额（已支付订单 payAmount 求和）、库存预警数
  - `orderTrend`：按日（近30天）/按月（近12个月）统计订单数和销售额，连续日期补零
  - `orderCategory`：从已支付订单明细按奶品品类汇总数量，饼图数据
  - `classRanking`：按班级统计订单数和销售额，降序，limit
  - `nutritionDashboard`：营养总摄入 + 平均每日每生摄入，可选按班级筛选
  - `coverage`：总覆盖率 + 各班级覆盖率
- **Controller**：重写 `StatsController`，6 个接口（原 TODO 空壳全部实现）

### 前端

- `Dashboard.vue`：保留原有 template 和 style，重写 script——导入 stats API，onMounted 时并行调用 5 个接口，把返回数据填入 4 个 ECharts 图表（趋势折线、品类饼图、班级排行柱状图、覆盖率仪表盘）
- 图表样式优化：加 grid 边距、柱状图圆角、饼图图例、配色统一

## 影响范围

- 后端：stats 模块全部（新建 Service + VO，重写 Controller）
- 前端：Dashboard.vue（script 重写，template/style 保留）
- 数据库：表结构无变化
- 接口文档：stats 章节同步（各接口返回数据说明）
