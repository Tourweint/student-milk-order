# 2026-09-10 班级与学生模块实现

## 变更背景

认证与用户权限模块完成后，按既定顺序实现第二个模块：班级与学生（clazz）。它是订单模块的数据基础——学生是订奶主体，班级是班主任数据权限与配送、统计的组织维度。

## 变更内容

### 后端

1. **年级（Grade）**：
   - `GradeService` 增加 `listOrdered`（按 sort 排序）、`createGrade`、`updateGrade`、`removeGrade`
   - 年级名称唯一校验；删除时若其下仍有班级则禁止删除

2. **班级（ClassInfo）**：
   - `ClassInfoService` 增加 `pageClasses`（分页 + 年级名/班主任名回填）、`listAll`（下拉用）、`createClass`、`updateClass`、`removeClass`、`refreshStudentCount`
   - 新增 `ClassVO`：附带 gradeName、teacherName，避免前端二次查询
   - 班级名称唯一校验、年级/班主任存在性校验；删除时若其下仍有学生则禁止删除
   - 学生增删导入后自动维护 `student_count` 冗余字段

3. **学生（Student）**：
   - `StudentService` 增加 `pageStudents`（班级 + 关键词筛选，关键词匹配学号/姓名/家长姓名/家长电话）、`createStudent`、`updateStudent`、`removeStudent`、`isStudentNoExists`
   - 新增 `StudentVO`：附带 className
   - 学号唯一校验；换班时同步刷新新旧两个班级人数
   - **Excel 批量导入**（Apache POI）：`importStudents(MultipartFile, classId)`，列顺序为 学号/姓名/性别(男·女)/家长姓名/家长电话/备注；逐行校验、文件内与库内学号去重，返回 `ImportResultVO`（成功数、失败数、逐行错误明细），单事务批量落库
   - **导入模板下载**：`GET /clazz/student/template`，POI 生成带表头和示例行的 .xlsx

4. **Controller**：重写 `ClassController`，由 TODO 空壳变为 18 个可用接口；新增 `/class/all`、`/class/teachers`、`/student/template` 三个接口
5. **用户模块扩展**：`SysUserService` 增加 `listByRoleCode(roleCode)`，支撑班主任下拉
6. **关联查询避免 N+1**：VO 转换时先批量查出关联年级/班主任/班级再内存组装
7. **避免循环依赖**：年级删除校验用 `ClassInfoMapper`、班级删除校验用 `StudentMapper` 直接计数，而非反向注入 Service

### 前端

1. **班级管理页** `ClassManage.vue`：el-tabs 分「年级管理 / 班级管理」
   - 年级：表格 + 新增/编辑对话框（名称/编码/排序/备注）+ 删除
   - 班级：年级筛选、表格（班级名/年级/班主任/人数/备注）、新增/编辑对话框（年级必选、班主任下拉可空）、分页
2. **学生管理页** `StudentManage.vue`：
   - 班级级联下拉（显示「年级 · 班级名」）+ 关键词搜索
   - 学生表格、新增/编辑对话框（学号/姓名/性别/班级/家长信息/出生日期/备注）、删除
   - **批量导入对话框**：先选班级再传 Excel，导入后展示成功/失败统计与逐行错误
   - **下载导入模板**（blob 下载）
3. **API 封装**：`api/clazz.ts` 增加 getAllClass、getTeacherOptions；`api/student.ts` 的 importStudents 增加 classId 参数、新增 downloadStudentTemplate
4. **请求基础设施**：`utils/request.ts` 响应拦截器对 blob/arraybuffer 二进制响应直接放行，避免被业务状态码判断误杀

### 数据

- `data.sql` 新增演示班主任账号 **teacher / 123456**（TEACHER 角色，关联一年级1班），一年级1班回填 teacher_id
- 当前运行库已同步该账号，并物理清理了前序测试遗留的逻辑删除数据

## 影响范围

- 前端：clazz 两个页面、两个 api 封装、request 拦截器
- 数据库：data.sql 初始数据补充；接口文档 clazz 章节同步
